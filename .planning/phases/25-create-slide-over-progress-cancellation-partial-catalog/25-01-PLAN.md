## Threat model

### Trust boundaries

| Boundary | Description |
|----------|-------------|
| renderer JS → Wails bound methods | Any script running in the webview can call `StartScan` with arbitrary strings; the native dialog is not the only possible caller |
| user-chosen source volume → catalog data | Filenames on a scanned volume are attacker-influenceable in the sense that a user may catalog media authored elsewhere |
| catalog data → output directory write | A new file-write path is created into a user-configured directory |

### STRIDE threat register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-25-01 | Tampering | `App.StartScan` — free-text `outputRoot` joined onto `outputDir` | high | mitigate | Reject before any write: both the `.json` and `.html` destinations must resolve inside `outputDir` per `osutil.ContainsPath`; asserted by `TestStartScan_RejectsEscapingOutputRoot` |
| T-25-02 | Tampering | `App.StartScan` — `opts.CopyToDirectory` | medium | mitigate | The same containment check is applied to the secondary-copy destinations before `WriteCatalogFrom` runs |
| T-25-03 | Denial of Service | `App.StartScan` — unbounded concurrent invocation from renderer JS | medium | mitigate | One mutex-guarded `activeScanCancel`; a second call returns an error and starts no walk; asserted by `TestStartScan_RejectsSecondConcurrentScan` |
| T-25-06 | Tampering | `writeHTMLFile` — hostile filename from the scanned volume rendered into the HTML catalog | medium | mitigate | The existing `html.EscapeString` on both title and item name stays unchanged; `TestCreateCatalog_JSONShapeUnchanged` and the HTML root-node test guard the escape path |
| T-25-07 | Information Disclosure | `scan:progress` broadcasts absolute filesystem paths into the webview | low | accept | Single-user local desktop app; the webview is the application's own UI and already renders these paths by requirement (CRT-07) |
| T-25-SC | Tampering | Dependency supply chain | high | mitigate | No package-manager install task in this plan. `25-RESEARCH.md`'s Package Legitimacy Audit records zero `[ASSUMED]`, `[SUS]` or `[SLOP]` packages; the sole entry is an OK-verdict promotion of an already-resolved `go.sum` module, so no blocking legitimacy checkpoint is required |
