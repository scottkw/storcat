| Boundary | Description |
|----------|-------------|
| renderer JS → Wails binding | `SetWriteHTML`, `SetCopyToSecondary`, `SetWatchDirectory` and the pre-existing `SetWindowPersistence` all accept arbitrary booleans from any script in the webview |

| config → window geometry restore at `domReady` | Config-sourced integers are passed to the Wails window-sizing runtime at launch |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-26-19 | Tampering | Renderer JS flipping persisted toggles directly through the bindings | low | mitigate | All four values are booleans with no path, no string and no privilege attached; each is consumed only as a default the user can see and change in Settings, and the write-HTML/copy-to-secondary values are re-read by the create form where they are visible before any scan runs |
| T-26-20 | Elevation of Privilege | The stored secondary directory becoming a write destination outside anywhere the user intended | high | mitigate | Unchanged from Phase 25: `App.StartScan` already resolves the output and secondary-copy destinations through `filepath.EvalSymlinks` and gates both with `osutil.ContainsPath` before writing. | T-26-21 | Spoofing | The watch-directory toggle implying an active watcher that does not exist | medium | mitigate | The toggle persists its value and surfaces nothing else: no status-bar segment, no rail badge, no "watching" copy anywhere in this milestone. | T-26-22 | Denial of Service | A hostile or corrupt window geometry in config restoring the window off-screen or at zero size at launch | low | accept | Pre-existing behaviour, unchanged by this phase: `domReady` already skips a `(0,0)` position and this plan adds no new write path to the geometry fields. | T-26-SC | Tampering | npm / Go module installs | high | accept | No package is installed by this plan — 26-RESEARCH.md's Package Legitimacy Audit records "Not applicable" for the whole phase |
