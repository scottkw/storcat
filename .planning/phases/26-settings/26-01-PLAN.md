**Go — `internal/config/config.go`.** Add two fields to `Config` following the existing struct-tag style: `Density string` tagged `density`, and `SettingsMigrated bool` tagged `settingsMigrated`. Add `SetDensity(density string) error` and `SetSettingsMigrated(migrated bool) error`, each the same three-line mutate-then-`return m.Save()` shape `SetTheme` already uses.

Add a `sync.RWMutex` field `mu` to `Manager`. Every method that touches `m.config` takes it: `Load`, `Save`, `Get` and all setters. Setters take the write lock, mutate, and call an unexported `saveLocked()` that holds no lock of its own (so the exported `Save()` can keep taking the lock itself without a double-acquire). `Get()` takes the read lock and returns a **pointer to a copy** of the struct, not `m.config` itself — this is a deliberate behavior change: `App.GetConfig`, `domReady` and `beforeClose` all only read fields off the result, and the copy is what makes concurrent `Set*` calls arriving on different Wails goroutines race-free. Document this in a comment on `Get()`.
