Extend `AppContext.tsx` with three action variants, following the file's existing spread style exactly. `TOGGLE_EXPAND` carries a node path and flips that key in `expanded`, deleting it or setting it false when it was true — a synchronous reducer flip, so a burst of clicks applies in order with no lost update. `SET_EXPANDED` carries a whole `Record<string, boolean>` and replaces the map; expand-all and collapse-to-root both use it, which is why neither needs a per-node dispatch loop. `SET_SELECTED` carries a node path or null.

Do not add a separate expand-all action that walks nodes inside the reducer. The reducer has no access to the node array and should not gain any; the component computes the map and hands it over.

Create `frontend/src/lib/format.ts` as the phase's only number and date formatting module, with a block comment above each export explaining what contract it implements. Plans 23-04, 23-05 and 23-06 import from it and must not need to edit it, so its surface is fixed here.

`formatBytes(bytes: number): string` is a TypeScript port of Go's `formatBytes` and must agree with it value for value: zero renders as `0B`; below 1024 renders as the integer followed by `B`; above that it divides by 1024 through the suffixes `K`, `M`, `G`, `T`, formats to one decimal place, and strips a trailing `.0`. This is the format the rail row, the tree row size column and the header metadata line all use.

`formatCount(n: number): string` renders a file count. Below one million it uses locale grouping, matching the prototype's own helper. At one million and above it abbreviates to one decimal place followed by `M`, because `23-UI-SPEC.md`'s status-bar overflow rule requires counts that grow into the millions to shorten rather than push a segment off a fixed-height strip.

`formatGB(bytes: number): string` renders a byte total as the status bar's third segment. It divides bytes by 1024 cubed once, then follows the prototype's `gb` helper: at 1024 and above it divides again and suffixes ` TB`, otherwise it suffixes ` GB`, always to one decimal place. The threshold is inclusive — exactly 1024 gigabytes renders as terabytes. Divide once from the byte total; never sum values that have already been rounded for display.

`formatDate(iso: string): string` renders a catalog's modification timestamp from the RFC3339 string the Go layer already produces, as a short local date. An unparseable input returns the original string unchanged rather than the word browsers produce for an invalid date.

Leave `useVisibleRows.ts` semantically unchanged; touch it only if the expanded-map key type needs widening. Its rule — a node is visible when its parent is both visible and expanded — is load-bearing for every requirement in this plan.
