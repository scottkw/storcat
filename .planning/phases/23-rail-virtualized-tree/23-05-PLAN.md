| Boundary | Description |
|----------|-------------|

| catalog metadata → header | Title, filename, size and timestamp all originate outside this app |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-23-20 | Denial of usability | a pathologically long raw parser error | low | accept | Every string reaching the box is produced by Go's own error types, whose length is bounded by the error kind rather than by the catalog's contents, and `23-UI-SPEC.md` specifies the box verbatim with no maximum height. | T-23-21 | Information disclosure | the file meta row and the header's chips | low | accept | Both show the catalog's own filename, which the user chose and which already appears in the rail. No absolute machine path is introduced by either surface. |
