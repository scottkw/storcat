**Models.** Add `FlatNode` and `FlatCatalog` to `pkg/models/catalog.go`, additively — `CatalogItem` is not touched. `FlatNode` fields and JSON tags: `Name string` (`name`), `Path string` (`path`), `Type string` (`type`), `Size int64` (`size`), `Depth int` (`depth`), `ParentIdx int` (`parentIdx`), `HasChildren bool` (`hasChildren`). `FlatCatalog` fields: `Nodes []FlatNode` (`nodes`), `FileCount int` (`fileCount`), `TotalBytes int64` (`totalBytes`).

**Flatten.** Create `internal/search/flatten.go` with `func (s *Service) LoadCatalogFlat(filePath string) (*models.FlatCatalog, error)`. It calls `s.LoadCatalog(filePath)` and returns its error unwrapped through `fmt.Errorf` with the `%w` verb; it must perform no JSON decoding of its own, because the dual-format parse has exactly one home. Reject a root whose `Type` is neither `file` nor `directory` with an error naming the file and saying the document is not a catalog — this is the "valid JSON that is not a catalog" case in `23-UI-SPEC.md` E7.

The walk is a DFS in pre-order over the root's `Contents`, and **the root itself is not appended**. The root's direct children get `Depth` 0 and `ParentIdx` -1; every deeper node gets its parent's depth plus one and the parent's index in the slice being built. `Name` is `filepath.Base(item.Name)` and `Path` is `item.Name` verbatim — `internal/catalog/service.go` stores a full relative display path in that single field, so the split is mandatory and a regression here silently breaks row labels and the breadcrumb. `HasChildren` is true only for a directory with a non-empty `Contents`. Accumulate `FileCount` (nodes of type `file`) and `TotalBytes` (the sum of file `Size` values as `int64`, never a float) during the same walk. Guard the recursion with a package constant of 512: a node deeper than that returns an error naming the path and the limit rather than growing the stack.
