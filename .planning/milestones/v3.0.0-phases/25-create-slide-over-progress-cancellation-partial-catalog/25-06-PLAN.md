<objective>
Make the running scan legible and stoppable: the full live progress surface in both of its sub-states, a cancel that actually stops the walk from every applicable close path, and a hand-off to the status bar that lets the user get the scan back.

Purpose: CRT-07's percentage exists because this project refuses spinners — progress is always a real number. That rule is what forces the two sub-states, and it is what makes the counting case interesting: there is a moment where no percentage exists, and the honest answer is to show a live file count and no bar at all rather than an indeterminate animation. CRT-08's hand-off then has to survive the panel unmounting, which is why the step state lives in shared state.

Output: the scanning body, the cancellation wiring, and the status bar's first right-aligned segment.
</objective>
