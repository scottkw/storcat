Do not add a resize listener — a `matchMedia` subscription fires only on threshold crossings, whereas a resize listener fires on every pixel.

If plan 22-01's ladder drifted, correct it here.

Do not add a second media query, a container query, or any width branch inside a pane component. This hook call is the single place React is allowed to know the tier.
