RESEARCH Open Question #1 — does `⌘K` actually reach a `window` keydown listener inside macOS WKWebView? — could not be settled from the repository or from any authoritative source. Output: an observed, recorded answer for ⌘K delivery in the packaged webview; live evidence for PLT-01, PLT-02 and PLT-03 against a real multi-catalog directory; and any defect repair the evidence demands in the tracer's own files.
</objective>
