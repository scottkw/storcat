## Flagged assumptions (specless probe — unresolved rows)

The deterministic edge probe returned four `unclassified` rows. PLT-01 and PLT-03 are flagged in 24-01 (PLT-01 resolved by 24-02's gate), PLT-07 in 24-03. **This plan owns PLT-04:**

- **PLT-04 (unclassified)** — "keyboard navigation + Escape dismiss". Three assumptions carried explicitly rather than silently:
  1. **Assumption:** keeping DOM focus on the input while a roving `aria-activedescendant` tracks the active option is the right pattern here. `24-UI-SPEC.md` specifies `role="listbox"` with `role="option"` rows and roving `tabIndex`, and notes the rows "are not natively tabbable". Focus never actually moving off the input is the natural consequence, but it is inferred from that description rather than stated by it.
  2. **Assumption:** the measured page step — viewport height divided by measured row height — is stable enough to be useful. `24-UI-SPEC.md` requires it be computed rather than hardcoded, with a fixed fallback of 10 when the viewport cannot be read yet. The fallback is specified; the measurement's stability across the two density tokens is not.
  3. **Assumption:** Escape reaching the palette from inside the input is delivered by plan 24-03's shared hook and needs no keyboard handling in this plan. The keydown handler this plan adds to the input must therefore leave Escape alone entirely — intercepting it here would produce two close paths for one press.
