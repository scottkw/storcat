<objective>
Build the Catalogs section's two value rows (SET-04's catalog directory and default filename root) and land the one-time `localStorage` → Go-config migration that makes the config the single source of truth.

Purpose: this is the plan that actually closes the two-store split 26-CONTEXT.md names as "the actual defect being fixed here". Phase 22 deferred it ("theme stays local pending Phase 26's Settings-owned theme state") and Phases 23 and 25 each bootstrapped their own `localStorage` directory key ahead of Settings existing. After this plan there is one source of truth (the Go config) and one boot cache (`localStorage`), written through together in the same handler, with an explicit marker-gated migration carrying every existing user's values across.

Output: three new config fields with setters and bindings; the `AppSettings` reducer slice; a `CatalogSettingsSection` component; `hydrateSettings()`; and the rail, create slide-over and options toggles all reading and writing the shared values rather than their own private copies.
</objective>
