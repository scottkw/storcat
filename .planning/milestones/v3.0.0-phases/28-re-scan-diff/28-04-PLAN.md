Turn the diff into a decision: overwrite, keep both, or discard.

overwrite path has no recovery — the previous catalog's bytes are gone the instant the rename completes.

one thing that could silently drift from the crash-safety guarantee ACT-09 already proved.

Output: `WriteRescanResult`, the `ResolveRescan` binding, and the three-button resolution footer.
